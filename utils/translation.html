se Hanumantha ha rimandato la gestione a noi, possiamo eventualmente verificare le dimensioni del file da caricare e, sulla base di questo, decidere come procedere.

Se il file è di dimensioni contenute, possiamo valutare di includere la creazione della tabella nella release, caricando il file su GitHub e attendendo quindi la release per il relativo deploy.

Se invece il file dovesse essere di dimensioni rilevanti, sarà necessario accordarci con Hanumantha per effettuare un caricamento extra-release, in quanto attualmente solo il loro team è abilitato tramite CyberArk a effettuare il caricamento dei file in produzione.

Un altro aspetto da verificare riguarda il contenuto del file. Se dovesse contenere dati dei clienti, ad esempio Codice Fiscale o nome e cognome, il caricamento su GitHub potrebbe essere problematico, in quanto tali dati risulterebbero potenzialmente visibili agli utenti con accesso ai repository. In questo caso sarebbe quindi più opportuno procedere con il caricamento tramite CyberArk.

A quel punto, dovremmo chiedere al team L2 di effettuare il caricamento tramite apposita SR.
