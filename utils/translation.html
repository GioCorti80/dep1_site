The reported vulnerabilities affect the Docker image of app-cloud-run, the microservice exposing the CreditValidator endpoint.

The fixes have been implemented, merged into the main branch, and successfully deployed to the development environment.

Deployment to UAT is currently blocked because the GitHub Service Account lacks the required permissions to access Google Secret Manager, preventing the Cloud Run deployment.

As an alternative, we could consider deploying directly to production, since UAT does not receive traffic to the CreditValidator endpoint, limiting the value of end-to-end testing.

The deployment could be included in the 30 July release, but is more likely to be part of the 27 August release. Given this timeline, we should evaluate whether the vulnerability remediation can be deferred until the August release based on the associated risk.
